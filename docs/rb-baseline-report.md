# 螺纹钢趋势策略基准回测

运行日期：2026-07-24。此报告仅用于策略研究，不构成投资建议或模拟/实盘交易许可。

## 数据

- 标的：新浪 `RB0` 螺纹钢主力连续日线，经 AKShare 下载。
- 实际范围：2015-01-05 至 2026-07-24，共 2,809 根日线。
- 原始文件与标准化文件均保存在本地 `data/`，并不提交版本库；其元数据文件记录了下载时间和来源。
- 主力连续序列不是单一可交易合约，且提供方的换月与历史处理规则可能调整。因此本结果不等同于可实盘复现的收益。

## 假设

- 收盘产生信号、下一交易日开盘成交；不使用同一根 K 线的未来信息。
- 趋势过滤：SMA(5) 与 SMA(20)。
- 入场/退出：唐奇安 20/10 日通道。
- 风险：ATR(20)、每笔 1% 资金风险、最多 4 手。
- 合约乘数 10，单边手续费率 0.01%，滑点 1 个最小价位。
